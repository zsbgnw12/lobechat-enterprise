# 客户字段对照

来源：`enterprise/integrations/gongdan-api.md` 的客户模块。本表只给对话口径，不代替接口调用。

| 能查         | 一线工具 | 说明             |
| ------------ | -------- | ---------------- |
| 客户列表     | 可以     | 用编号或名称核对 |
| 单个客户     | 可以     | 以工具返回为准   |
| 创建客户     | 不可以   | 仅 OPERATOR      |
| 更新客户等级 | 不可以   | 仅 OPERATOR      |
| 绑定工程师   | 不可以   | 仅 OPERATOR      |

工单侧若要挂到指定客户，走「为指定客户创建工单」，不要先假装客户已建好。

查客户、挂工单一律走对话里的「工单 / 客户」工具。
